# 5W tentang Spring Framework

### 1. What (Apa itu Spring?)
Spring adalah *framework* aplikasi *open-source* dan wadah *Inversion of Control* (IoC) untuk platform Java. Spring Boot (ekstensi dari Spring) menyederhanakan konfigurasi sehingga pengembang bisa langsung membuat aplikasi yang bisa dijalankan (*production-ready*).

### 2. Why (Mengapa menggunakan Spring?)
Mengurangi *boilerplate code* (kode yang berulang) dan memastikan aplikasi modular (terpisah-pisah namun saling terhubung) melalui *Dependency Injection* (DI). Spring memiliki ekosistem yang luas (Spring Security, Spring Data JPA, dll) yang mempercepat proses pengembangan.

### 3. Who (Siapa pembuat dan penggunanya?)
Diciptakan pertama kali oleh Rod Johnson pada tahun 2003. Saat ini dikelola oleh VMware/Pivotal. Digunakan oleh para pengembang *backend* Java (seperti dalam pengembangan aplikasi *full-stack*) dan perusahaan tingkat *enterprise*.

### 4. When (Kapan Spring digunakan?)
Digunakan saat Anda perlu membangun aplikasi *backend* Java berskala besar, REST API, *microservices*, atau sistem yang membutuhkan integrasi *database*, keamanan, dan manajemen transaksi yang tangguh.

### 5. Where (Di mana Spring diterapkan?)
Di sisi server (*backend*). Spring sering digabungkan dengan basis data relasional, berjalan di atas server seperti Apache Tomcat, dan di-*deploy* di lingkungan cloud atau container (seperti Docker).
